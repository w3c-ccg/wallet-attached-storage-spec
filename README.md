# Wallet Attached Storage spec (moved)

The Wallet Attached Storage (WAS) specification has been renamed to
Portable Web Spaces (PWS) and now lives at
<https://github.com/w3c-ccg/portable-web-spaces-spec>.

Rendered spec: <https://w3c-ccg.github.io/portable-web-spaces-spec/>

This repository exists only so that the old GitHub Pages URL,
<https://w3c-ccg.github.io/wallet-attached-storage-spec/>, keeps working.
GitHub redirects renamed repositories but not their Pages sites, so
`index.html` here redirects visitors to the new location.
